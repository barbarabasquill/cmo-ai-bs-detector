# Steal the Prompts

**Choose the prompt. Add your facts. Make the final call.**

Steal the Prompts is the interactive, copy-ready prompt library inside **The CMO's AI BS Detector**. It helps CMOs and marketers find a useful prompt without needing to become prompt engineers.

## What the page does

The **Easy-Peezy Prompt Finder** lets a marketer describe a job in plain English, choose ChatGPT, Claude, or a universal format, and receive the strongest prompt match plus two alternatives.

The complete library remains visible below the finder for people who prefer to browse.

Each prompt includes:

- A plain-English purpose
- Guidance on when to use it
- A tool-appropriate structure
- Optional company, audience, evidence, and deliverable details
- Prompt Power-Ups for stronger instructions
- A finished prompt that can be copied with one click
- Human-review and evidence guardrails

## The prompt library

### Audit and verify

1. **Detect the BS** — audit evidence, specificity, strategy, voice, and risk
2. **Verify the Claims** — build a verification queue for facts, numbers, quotations, and comparisons
3. **Challenge My Assumptions** — expose confirmation bias, missing alternatives, and decision risk

### Repair the work

4. **Fix This Crap** — repair a weak draft without inventing proof
5. **Remove Corporate Oatmeal** — replace vague language with useful meaning
6. **Make It Sound Human** — remove robotic rhythm while preserving credibility

### Strategy and campaigns

7. **Turn Tactics into Strategy** — add choices, sequencing, ownership, tradeoffs, and measurement
8. **Pressure-Test the Campaign** — find weak links before launch
9. **Build the Executive Brief** — convert marketing detail into a decision-ready narrative

### Revenue and ABM

10. **Pipeline Reality Check** — challenge attribution and pipeline claims
11. **Prioritize the Accounts** — rank accounts using visible evidence and missing-data rules
12. **Build the Sales Follow-Up Brief** — turn engagement into responsible sales action

## Privacy by design

The finder and builder run entirely in the visitor's browser.

- No login or account connection
- No API calls
- No analytics or tracking scripts
- No searches or customization details stored
- Nothing sent to ChatGPT or Claude

The page assembles a prompt for the user to copy. It does not run the prompt or access an AI account.

Use nonconfidential information and paste the finished prompt only into an AI tool approved by your organization.

## How to use it

1. Open the live prompt library.
2. Describe what you want to accomplish.
3. Choose ChatGPT, Claude, or **Works with either**.
4. Review the recommended prompts.
5. Add optional facts and Prompt Power-Ups.
6. Copy the finished prompt into an approved AI tool.
7. Verify the output before anyone acts on it.
