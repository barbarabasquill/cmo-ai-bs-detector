## Easy-Peezy Marketing Skills

**Sixty-two copy-ready AI skills for CMOs who want the work done—without jargon, prompt theater, or corporate oatmeal.**

Created by **Barbara Basquill**, these agent-readable skills help CMOs plan campaigns, diagnose pipeline, build ABM plays, create content, allocate budget, prepare board narratives, review AI output, and move from question to decision. Every skill includes evidence checks, human approval gates, executive-ready outputs, and measurable success criteria.
