# CMO Scaled Search Pages

## Outcome

Evaluate and plan template-driven search pages that remain genuinely useful at scale.

## Start with

- search pattern, unique data, template value, indexation constraints, production capacity

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Validate demand and unique value
2. **Ground:** define page types
3. **Decide:** specify required data and quality floor
4. **Build:** design internal links
5. **Control:** pilot a small set
6. **Learn:** monitor indexation and utility

## Deliver

- opportunity assessment, template spec, data contract, pilot plan, quality controls

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not generate thin, duplicated, doorway, or fabricated pages. Prefer noindex when value is insufficient.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- indexed useful pages, qualified organic demand, conversion, crawl efficiency, content defects

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
