# CMO ABM Command

## Outcome

Prioritize accounts, buying groups, plays, and orchestration for a focused account-based growth motion.

## Start with

- target market, account data, intent and engagement, buying roles, sales capacity, proof

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define the business case
2. **Ground:** select and tier accounts with transparent criteria
3. **Decide:** map buying groups
4. **Build:** match plays to account state
5. **Control:** align sales actions
6. **Learn:** set progression and stop rules

## Deliver

- ABM charter, tier model, buying-group map, play matrix, weekly account review

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Intent is a signal, not consent or certainty. Avoid sensitive inference and fake personalization.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- engaged target accounts, buying-group coverage, account progression, opportunity creation, pipeline quality

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
