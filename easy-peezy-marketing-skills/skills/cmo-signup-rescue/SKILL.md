# CMO Signup Rescue

## Outcome

Reduce unnecessary signup friction while protecting qualification, trust, security, and downstream success.

## Start with

- flow, required data, error data, audience, risk controls, activation path

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Clarify the value moment
2. **Ground:** challenge each field and step
3. **Decide:** improve error handling
4. **Build:** preserve security and consent
5. **Control:** connect signup to activation
6. **Learn:** test segmented friction

## Deliver

- flow diagnosis, field decision table, copy, experiment plan, QA checklist

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not weaken authentication or consent merely to improve completion. Distinguish bots and low-fit signups from real friction.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- qualified completion, error rate, time to signup, activation, abuse rate

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
