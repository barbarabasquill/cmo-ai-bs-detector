# CMO Repeatable Growth Loop

## Outcome

Design a recurring marketing workflow with a trigger, state, human checkpoint, and stop condition.

## Start with

- cadence, trigger, inputs, systems, permitted actions, owner

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define the decision loop
2. **Ground:** specify check cadence
3. **Decide:** require no-action as a valid outcome
4. **Build:** record state
5. **Control:** place approvals before external action
6. **Learn:** add failure and stop rules

## Deliver

- loop specification, trigger table, state model, approval gate, audit log design

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Never allow autonomous publishing, sending, spending, deleting, or customer changes without explicit authorization.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- useful actions per run, false alarms, hours saved, approval rate, incident rate

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
