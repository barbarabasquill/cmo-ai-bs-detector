# CMO Market Foundation

## Outcome

Create the shared market context that every other Easy-Peezy skill uses: audience, problem, promise, proof, objections, and constraints.

## Start with

- product facts, target segments, research, category, alternatives, proof, limits

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Separate facts from assumptions
2. **Ground:** define ICP and disqualifiers
3. **Decide:** articulate problem and change
4. **Build:** build message hierarchy
5. **Control:** catalogue proof and objections
6. **Learn:** assign freshness owners

## Deliver

- market foundation brief, claims ledger, evidence gaps, message hierarchy, update cadence

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Never fill gaps with plausible fiction. Use unknown, hypothesis, and verified labels.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- field adoption, message consistency, win-loss signal, content reuse, evidence freshness

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
