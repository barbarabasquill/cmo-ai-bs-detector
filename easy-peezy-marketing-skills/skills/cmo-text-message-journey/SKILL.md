# CMO Text-Message Journey

## Outcome

Design permission-based SMS journeys that earn attention through relevance, brevity, and restraint.

## Start with

- consent source, audience state, purpose, timing, frequency, jurisdiction

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Confirm permission
2. **Ground:** define one job per message
3. **Decide:** write concise value
4. **Build:** set quiet hours and frequency
5. **Control:** create STOP and suppression handling
6. **Learn:** measure downstream quality

## Deliver

- journey map, message drafts, trigger logic, compliance checklist, dashboard

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Explicit consent, identification, opt-out, quiet hours, and applicable legal review are mandatory.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- delivery, response or click, qualified conversion, opt-out, complaint rate

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
