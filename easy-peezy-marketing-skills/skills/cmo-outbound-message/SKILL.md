# CMO Outbound Message

## Outcome

Create concise B2B outreach grounded in a real trigger, relevant value, and respectful follow-up.

## Start with

- recipient role, account trigger, credible proof, offer, sender identity

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Verify the trigger
2. **Ground:** write one relevance line
3. **Decide:** connect a business problem to proof
4. **Build:** make a low-friction ask
5. **Control:** build restrained follow-up
6. **Learn:** define suppression rules

## Deliver

- email sequence, personalization fields, proof checklist, routing notes

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

No fabricated personalization, misleading reply chains, purchased-sensitive data, or evasion of opt-out requirements.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- positive reply rate, meetings held, qualified opportunity rate, complaints, opt-outs

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
