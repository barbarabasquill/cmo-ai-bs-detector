# CMO Lifecycle Email

## Outcome

Design an email journey that advances a specific customer decision instead of sending disconnected messages.

## Start with

- entry trigger, audience state, desired behavior, proof, timing, suppression rules

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define the state change
2. **Ground:** map message jobs
3. **Decide:** sequence value and proof
4. **Build:** personalize only with trusted data
5. **Control:** set exits and suppressions
6. **Learn:** specify measurement

## Deliver

- journey map, email briefs, draft sequence, logic table, QA checklist

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Respect consent and frequency. Never imply actions or knowledge not supported by data.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- progression, qualified clicks, conversion, unsubscribe rate, revenue per recipient

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
