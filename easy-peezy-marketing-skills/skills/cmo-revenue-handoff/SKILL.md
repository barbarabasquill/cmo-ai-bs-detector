# CMO Revenue Handoff

## Outcome

Design the lifecycle, definitions, routing, service levels, and feedback that connect marketing work to revenue.

## Start with

- funnel definitions, systems, ownership, capacity, exceptions, revenue goals

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define lifecycle states
2. **Ground:** set entry and exit criteria
3. **Decide:** map routing and exceptions
4. **Build:** establish service levels
5. **Control:** create feedback reasons
6. **Learn:** monitor leakage and quality

## Deliver

- lifecycle map, definitions, routing matrix, SLA, exception dashboard

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not hide weak demand behind stage inflation. Minimize unnecessary personal data and document system ownership.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- acceptance, speed-to-lead, stage conversion, leakage, pipeline velocity

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
