# CMO LLM Security Gate

## Outcome

Decide whether information and workflows are appropriate for an approved LLM before any content is entered or automated.

## Start with

- workspace type, data classification, vendor settings, retention, integrations, approval policy

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Classify data green, amber, or red
2. **Ground:** verify business workspace controls
3. **Decide:** minimize inputs
4. **Build:** check connectors and retention
5. **Control:** require approvals for external action
6. **Learn:** document owner and review date

## Deliver

- security setup checklist, data gate, approved-use matrix, escalation questions, review cadence

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Never treat temporary or incognito chat as permission to upload restricted data. Stop on credentials, regulated data, secrets, or unclear authority.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- approved use, policy compliance, connector inventory, incidents, review completion

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
