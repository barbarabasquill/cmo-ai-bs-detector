# CMO App-Store Growth

## Outcome

Create an app-store growth plan spanning discovery, listing conversion, reviews, and experiments.

## Start with

- category, target user, store data, review themes, screenshots, release calendar

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Diagnose discoverability and conversion separately
2. **Ground:** map keywords to intent
3. **Decide:** rewrite positioning
4. **Build:** storyboard screenshots
5. **Control:** plan ethical review generation
6. **Learn:** prioritize experiments

## Deliver

- listing brief, keyword themes, screenshot story, review plan, test backlog

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not use incentivized or fabricated reviews. Distinguish observed store data from assumptions.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- impressions, product-page views, install rate, review velocity, qualified activation

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
