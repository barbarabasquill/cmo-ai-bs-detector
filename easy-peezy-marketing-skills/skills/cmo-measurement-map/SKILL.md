# CMO Measurement Map

## Outcome

Design a practical measurement system that connects activity to decisions and revenue.

## Start with

- business questions, funnel stages, systems, decision cadence, owners

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Start with decisions
2. **Ground:** define metrics and formulas
3. **Decide:** map required events and fields
4. **Build:** assign system of record
5. **Control:** document QA
6. **Learn:** create an exception-focused executive view

## Deliver

- measurement map, KPI dictionary, event plan, dashboard wireframe, QA checklist

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not imply precision that the data cannot support. Identify missing joins, changing definitions, and consent constraints.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- coverage, data freshness, funnel conversion, pipeline velocity, decision adoption

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
