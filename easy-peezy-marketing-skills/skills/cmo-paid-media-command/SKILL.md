# CMO Paid Media Command

## Outcome

Build or audit a paid-media plan around business economics instead of platform activity.

## Start with

- revenue target, ICP, ACV, sales cycle, conversion rates, budget ceiling

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Translate revenue target into pipeline and response requirements
2. **Ground:** choose channel roles
3. **Decide:** define audience and offer
4. **Build:** set budget tests
5. **Control:** specify kill, keep, and scale rules

## Deliver

- one-page media plan, budget table, campaign map, weekly decision dashboard

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not optimize to cheap leads when sales quality is the constraint. Separate platform-reported conversions from accepted pipeline.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- CAC, cost per qualified meeting, opportunity rate, sourced pipeline, payback

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
