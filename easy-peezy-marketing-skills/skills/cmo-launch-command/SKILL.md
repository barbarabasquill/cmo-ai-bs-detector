# CMO Launch Command

## Outcome

Orchestrate a launch around market readiness, buyer proof, internal alignment, and post-launch learning.

## Start with

- launch type, audience, readiness, proof, channels, sales and support capacity

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Classify launch tier
2. **Ground:** define buyer change
3. **Decide:** validate readiness
4. **Build:** align message and proof
5. **Control:** coordinate internal and external activation
6. **Learn:** set day-one and day-thirty decisions

## Deliver

- launch brief, readiness checklist, message map, channel plan, command calendar, scorecard

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not market unavailable capabilities or overstate beta readiness. Include support, legal, security, and rollback considerations.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- target-account engagement, adoption, pipeline, retention signal, launch learning velocity

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
