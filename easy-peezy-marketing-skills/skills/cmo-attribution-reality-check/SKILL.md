# CMO Attribution Reality Check

## Outcome

Help leaders interpret attribution models without confusing reported credit with causal impact.

## Start with

- buyer journey, touch data, CRM stages, offline influence, reporting goal

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define the decision
2. **Ground:** diagram observable and dark touches
3. **Decide:** compare model answers
4. **Build:** expose missing data
5. **Control:** triangulate with experiments and self-report
6. **Learn:** state confidence

## Deliver

- model comparison, journey map, caveats, executive narrative, next measurement action

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Never present one attribution model as truth. Keep sourced, influenced, and incremental impact distinct.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- coverage, model variance, influenced pipeline, lift evidence, sales-confirmed source

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
