# CMO Behavioral Advantage

## Outcome

Apply behavioral science to reduce decision friction ethically and improve message comprehension.

## Start with

- audience decision, context, barriers, proof, desired action, ethical constraints

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Diagnose the decision friction
2. **Ground:** select relevant principles
3. **Decide:** design transparent interventions
4. **Build:** anticipate misuse
5. **Control:** test with real behavior
6. **Learn:** monitor unintended effects

## Deliver

- behavioral diagnosis, ethical intervention options, test plan, risk notes

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Never exploit vulnerability, manufacture scarcity, obscure costs, or use dark patterns.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- comprehension, decision completion, regret or complaints, qualified conversion, retention

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
