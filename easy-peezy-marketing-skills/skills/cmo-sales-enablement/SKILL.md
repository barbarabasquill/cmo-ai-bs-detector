# CMO Sales Enablement

## Outcome

Create sales assets and plays that help sellers make buyer conversations more relevant, credible, and consistent.

## Start with

- buyer situation, sales stage, proof, objections, competitive context, field feedback

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define the conversation job
2. **Ground:** map buyer questions
3. **Decide:** select proof
4. **Build:** build modular talk tracks
5. **Control:** prepare objections and next steps
6. **Learn:** pilot with sellers and update

## Deliver

- asset brief, seller-ready content, talk track, proof index, adoption plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not arm sellers with unsupported claims, stale comparisons, or promises outside approved terms.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- seller adoption, time-to-use, stage progression, win rate, content freshness

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
