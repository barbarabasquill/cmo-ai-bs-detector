# CMO Activation Journey

## Outcome

Design the path from signup to first meaningful value with clear ownership and behavioral evidence.

## Start with

- user goal, product events, friction, segments, support model, success threshold

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define meaningful activation
2. **Ground:** map shortest value path
3. **Decide:** remove nonessential steps
4. **Build:** create contextual guidance
5. **Control:** segment interventions
6. **Learn:** measure cohorts and handoffs

## Deliver

- activation map, message sequence, experiment backlog, event requirements, owner matrix

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not force unnecessary data collection or block value behind deceptive steps.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- activation rate, time-to-value, key action completion, early retention, support demand

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
