# CMO Upgrade Moment

## Outcome

Create transparent upgrade experiences that connect product value to the right commercial choice.

## Start with

- user state, value received, plan structure, eligibility, pricing, objections

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Identify the earned upgrade moment
2. **Ground:** explain value and limit
3. **Decide:** compare plans fairly
4. **Build:** reduce uncertainty
5. **Control:** design recovery paths
6. **Learn:** test conversion and regret

## Deliver

- upgrade brief, copy, plan comparison, trigger rules, experiment plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

No forced continuity, hidden fees, confusing defaults, or blocking access to previously promised value.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- upgrade rate, expansion revenue, downgrade or refund rate, retention, complaint rate

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
