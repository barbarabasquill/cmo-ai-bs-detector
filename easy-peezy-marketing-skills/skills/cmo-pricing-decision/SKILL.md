# CMO Pricing Decision

## Outcome

Structure a pricing decision using customer value, willingness to pay, competitive context, economics, and migration risk.

## Start with

- segments, value metric, research, costs, alternatives, current contracts

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Frame the pricing decision
2. **Ground:** segment value and willingness
3. **Decide:** evaluate metric and package options
4. **Build:** model economics
5. **Control:** test research and market response
6. **Learn:** plan migration and communication

## Deliver

- decision memo, option model, package architecture, research plan, rollout guardrails

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not infer willingness to pay from opinions alone or hide material changes from existing customers.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- conversion, ARPA, gross margin, expansion, churn, discount leakage

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
