# CMO Directory Launch

## Outcome

Prioritize and execute credible directory submissions without creating a low-quality listing treadmill.

## Start with

- category, audience, product facts, assets, geography, review policy

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Score directories by buyer relevance
2. **Ground:** prepare a verified listing kit
3. **Decide:** standardize claims
4. **Build:** assign ownership
5. **Control:** track status
6. **Learn:** measure downstream quality

## Deliver

- priority list, listing kit, submission tracker, review request template, QA checklist

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Avoid fabricated reviews, duplicate identities, undisclosed incentives, and inaccurate security or integration claims.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- listing views, referral quality, review velocity, assisted pipeline, maintenance cost

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
