# CMO Pipeline Diagnostic

## Outcome

Find where pipeline quality or velocity is breaking and identify the smallest set of corrective actions.

## Start with

- target, actuals, stage definitions, conversion, velocity, segment, source, capacity

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Validate definitions
2. **Ground:** locate the constraint
3. **Decide:** segment the problem
4. **Build:** distinguish volume, quality, conversion, and capacity
5. **Control:** test leading explanations
6. **Learn:** prioritize fixes with owners

## Deliver

- pipeline tree, constraint diagnosis, corrective plan, leading indicators, review cadence

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not prescribe more leads before checking acceptance, progression, sales capacity, and data integrity.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- coverage, acceptance, stage conversion, velocity, win rate, sourced and influenced pipeline

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
