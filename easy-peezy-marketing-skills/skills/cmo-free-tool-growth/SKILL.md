# CMO Free-Tool Growth

## Outcome

Evaluate and design a useful free tool that earns demand by solving a real buyer problem.

## Start with

- buyer problem, value exchange, data inputs, build capacity, conversion path

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Score the idea
2. **Ground:** define immediate user value
3. **Decide:** minimize data collection
4. **Build:** design result and next step
5. **Control:** plan distribution
6. **Learn:** set maintenance ownership

## Deliver

- concept scorecard, product brief, input-output spec, CTA model, launch plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not disguise lead capture as utility. Explain data use and avoid authoritative claims the tool cannot support.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- completion, repeat use, qualified capture, assisted pipeline, maintenance burden

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
