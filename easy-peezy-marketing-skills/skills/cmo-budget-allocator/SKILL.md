# CMO Budget Allocator

## Outcome

Allocate marketing resources across core growth, optimization, experimentation, and resilience using explicit assumptions.

## Start with

- revenue target, economics, commitments, performance ranges, capacity, risk appetite

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Translate goals into requirements
2. **Ground:** protect proven engines
3. **Decide:** fund constraint removal
4. **Build:** reserve learning budget
5. **Control:** model scenarios
6. **Learn:** define reallocation triggers

## Deliver

- allocation table, scenario model, tradeoff memo, trigger rules, executive recommendation

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Do not treat last-click ROAS as the sole allocation truth. Include people, content, systems, and lag effects.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- marginal pipeline, CAC, payback, capacity utilization, learning return

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
