# CMO Earned Media

## Outcome

Build a credible earned-media plan around a real story, evidence, spokesperson readiness, and responsible outreach.

## Start with

- news, proof, audience, spokesperson, timing, risk, target outlets

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Test newsworthiness
2. **Ground:** choose story angle
3. **Decide:** validate claims
4. **Build:** prepare assets and spokesperson
5. **Control:** target relevant journalists
6. **Learn:** create follow-up and crisis contingencies

## Deliver

- story brief, pitch, press kit checklist, Q&A, outreach plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

No fake exclusivity, fabricated trends, undisclosed pay-to-play, or mass irrelevant pitching.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- quality coverage, message pull-through, referral demand, spokesperson readiness, corrections

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
