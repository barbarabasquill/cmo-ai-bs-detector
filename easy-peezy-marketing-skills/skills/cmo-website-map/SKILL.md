# CMO Website Map

## Outcome

Plan a website structure that reflects buyer decisions, search intent, product complexity, and internal ownership.

## Start with

- audiences, buyer tasks, offerings, content inventory, search demand, technical constraints

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define top buyer tasks
2. **Ground:** group content by mental model
3. **Decide:** map hierarchy and navigation
4. **Build:** assign page jobs
5. **Control:** plan URLs and internal links
6. **Learn:** create migration and governance

## Deliver

- sitemap, navigation model, page-purpose table, migration checklist, governance plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Protect high-value URLs and redirects. Do not organize solely around the company org chart.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- task completion, qualified paths, organic stability, content findability, governance compliance

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
