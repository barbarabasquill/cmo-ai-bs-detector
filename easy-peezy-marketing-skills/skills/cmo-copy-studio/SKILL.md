# CMO Copy Studio

## Outcome

Draft decision-focused marketing copy using buyer language, credible proof, and a clear next action.

## Start with

- audience, problem, promise, proof, objections, voice, CTA

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Choose one job for the asset
2. **Ground:** write a buyer-centered message hierarchy
3. **Decide:** anchor claims in proof
4. **Build:** answer the main objection
5. **Control:** create CTA variants
6. **Learn:** run the BS review

## Deliver

- message hierarchy, primary draft, variants, proof gaps, approval notes

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Never invent customer quotes, results, integrations, compliance status, or urgency.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- message comprehension, action rate, qualified conversion, sales adoption, revision speed

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
