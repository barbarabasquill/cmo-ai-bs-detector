# CMO Event Pipeline

## Outcome

Build an event strategy that connects audience, experience, follow-up, and measurable commercial outcomes.

## Start with

- event role, audience, target accounts, budget, offer, sales capacity

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Define the commercial job
2. **Ground:** select the right event motion
3. **Decide:** design pre-event account plays
4. **Build:** build the experience
5. **Control:** create segmented follow-up
6. **Learn:** run a pipeline review

## Deliver

- event brief, account plan, run-of-show, follow-up matrix, ROI scorecard

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Separate attendance from impact. Require permission for attendee data use and disclose sponsored relationships.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- target-account attendance, meetings, accepted follow-up, influenced pipeline, cost per opportunity

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
