# CMO Referral Engine

## Outcome

Design a referral or affiliate motion that rewards genuine advocacy without distorting trust.

## Start with

- advocate, referred user, incentive economics, eligibility, fraud risk, disclosure rules

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Identify natural referral moment
2. **Ground:** design two-sided value
3. **Decide:** set eligibility and attribution
4. **Build:** create messaging
5. **Control:** add fraud controls
6. **Learn:** test cohort economics

## Deliver

- program brief, incentive model, journey, terms checklist, measurement plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Require disclosure where applicable. Prevent self-referral abuse and avoid incentives that encourage false reviews.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- participation, referred conversion, referred retention, CAC, fraud rate

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
