# CMO Answer-Engine Visibility

## Outcome

Improve how a brand is discovered, cited, and represented in AI-generated answers without making unsupported ranking promises.

## Start with

- priority questions, authoritative proof, entity facts, existing content, measurement access

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Map buyer questions
2. **Ground:** audit answer eligibility
3. **Decide:** strengthen evidence and entity clarity
4. **Build:** create quotable answer blocks
5. **Control:** distribute corroborating proof
6. **Learn:** monitor mentions and framing

## Deliver

- AI visibility plan, content brief, evidence gaps, measurement plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Treat visibility as probabilistic. Never promise placement or manufacture consensus across owned sites.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- brand mentions, citation quality, recommendation framing, assisted demand, self-reported attribution

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
