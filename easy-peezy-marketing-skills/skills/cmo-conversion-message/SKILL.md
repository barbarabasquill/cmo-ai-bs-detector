# CMO Conversion Message

## Outcome

Design restrained on-site messages that are relevant to visitor intent and do not damage trust.

## Start with

- page intent, visitor state, offer, timing, frequency, consent requirements

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Choose a legitimate interruption
2. **Ground:** define eligibility
3. **Decide:** write one clear value exchange
4. **Build:** set timing and frequency
5. **Control:** create suppression
6. **Learn:** test net impact

## Deliver

- message brief, copy variants, targeting rules, QA checklist, measurement plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Avoid deceptive close buttons, repeated interruption, coerced consent, and mobile obstruction.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- incremental conversion, dismissal, page completion, complaint rate, downstream quality

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
