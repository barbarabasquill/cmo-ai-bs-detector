# CMO Structured Data

## Outcome

Plan and quality-check structured data that accurately represents the page and organization.

## Start with

- page type, visible content, organization facts, technical environment, validation access

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Choose eligible schema
2. **Ground:** map only visible supported facts
3. **Decide:** generate or review markup
4. **Build:** validate syntax and eligibility
5. **Control:** deploy with ownership
6. **Learn:** monitor errors

## Deliver

- schema recommendation, field map, markup brief, validation checklist, monitoring plan

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Never mark up invisible, misleading, fake-review, or ineligible content. Rich results are not guaranteed.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- valid items, error rate, eligible enhancements, organic quality, maintenance freshness

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
