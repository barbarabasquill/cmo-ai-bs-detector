# CMO Comparison Page

## Outcome

Plan credible comparison and alternative pages that help buyers decide without cheap attacks.

## Start with

- buyer criteria, verified product facts, competitor facts, proof, legal limits

If a required input is unavailable, label it **Unknown** or **Assumption**. Do not fill gaps with plausible fiction.

## Easy-Peezy workflow

1. **Frame:** Choose the buyer decision
2. **Ground:** define fair criteria
3. **Decide:** source every factual comparison
4. **Build:** acknowledge legitimate fit differences
5. **Control:** write a useful decision guide
6. **Learn:** schedule review

## Deliver

- page brief, comparison matrix, claims ledger, CTA plan, refresh owner

Lead with the recommendation. Keep the main response to one executive page when practical; place working detail after it. End with **Decide now / Do next / Verify before use**.

## Human approval gate

Never fabricate weaknesses, imply endorsements, or present stale pricing and features as current.

External publishing, sending, spending, deleting, or system changes require explicit authorization.

## Score it with

- qualified organic traffic, assisted conversion, competitive win rate, page engagement, claim freshness

## Quality bar

- Tie every recommendation to a customer, commercial, category, or capability decision.
- Separate verified facts, reasonable inferences, and open assumptions.
- Remove corporate oatmeal and unsupported precision.
- Name an owner, a next action, and the evidence that would change the decision.
