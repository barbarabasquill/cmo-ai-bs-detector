# Easy-Peezy Marketing Skills

**Sixty-two agent-readable marketing skills for CMOs who want decisions and deliverables—not jargon, prompt theater, or 4,000 words of corporate oatmeal.**

Created by **Barbara Basquill**, this original collection translates the work of modern marketing leadership into practical, executive-ready AI workflows. It includes dedicated skills for ABM, integrated campaigns, customer expansion, board reporting, budget allocation, pipeline diagnosis, Signal 80, AI BS detection, LLM security, GTM schematics, agency briefing, and executive triage.

## The promise

Every skill is designed to:

- lead with the decision, not the methodology;
- use plain English and one-page executive outputs;
- distinguish facts, inferences, and assumptions;
- connect work to customer, commercial, category, or capability impact;
- require human approval before external action; and
- run the CMO AI BS standard before consequential use.

## Start here

1. Complete [The Five-Minute CMO Market Brief](context/cmo-market-brief.md).
2. Choose the skill closest to the decision you need to make.
3. Give the agent the brief plus relevant evidence.
4. Approve, challenge, or reject the recommendation—AI never owns the outcome.

## Installation

Copy the individual skill folders you want into the skills directory supported by your AI coding agent. Each folder contains a standards-compliant `SKILL.md` with matching YAML name metadata. You may also keep this collection inside a project repository and point your agent to the exact skill file.
